🌌 Proyectos destacados

🚀 NovaOS

Mi proyecto principal de sistemas operativos.

NovaOS es un sistema operativo experimental x86_64, desarrollado desde cero e independiente de Linux.

Actualmente el proyecto incluye diferentes componentes del kernel y userspace:

- 🧠 Physical Memory Manager
- 🗺️ Paging
- 💾 Kernel Heap
- 🔍 Diagnósticos de memoria
- ⚙️ GDT y TSS
- 🔒 Ring 3
- 🔄 Scheduler cooperativo
- 👤 Procesos y PID
- 🗂️ Page tables por proceso
- 🔐 Permisos de memoria
- 📦 Initramfs
- 📄 ELF64
- 🔌 Syscalls
- 📁 File descriptors
- 🧑‍💻 Userspace
- 🧪 Pruebas con QEMU
- 🤖 GitHub Actions

El desarrollo se realiza mediante milestones y pruebas automatizadas para comprobar que cada componente funciona correctamente.

🧠 CortexOS

Proyecto experimental centrado en sistemas operativos, kernel y userspace.

Algunos de los conceptos que exploro:

- ELF64
- ABI
- Syscalls
- VFS
- File descriptors
- Procesos
- "exec"

- "pipe"
- "dup2"
- "lseek"
- "isatty"
- "stat"
- "fcntl"

La idea es comprender mejor cómo se conecta el kernel con los programas que ejecutamos.
