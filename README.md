## English

**Languages:** English · Español

I build things to understand how they work underneath. Most of my time goes into
operating systems, memory management, emulation, and Android applications.

- **Systems** — x86_64 kernels, paging, physical memory management, process isolation, ELF64, syscalls, ABI
- **Emulation** — a Nintendo 64 emulator in C++20, with an in-progress MIPS interpreter
- **Android** — Kotlin and Jetpack Compose apps, plus a custom AOSP-based ROM
- **Tools** — a local-first coding agent in Go with a security layer, and reproducible Linux builders
